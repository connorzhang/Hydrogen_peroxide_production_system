# 双氧水生产控制系统

本项目用于 S7-200 SMART 双氧水生产平台，当前稳定版本由 PLC 顺控程序、网页调试面板、Rust/Slint 原生上位机和现场使用文档组成。系统核心工艺为电解槽将水分解为氢气和氧气，并利用氧气制备双氧水。

## 1. 当前稳定版本

| 模块 | 文件/入口 | 说明 |
|---|---|---|
| PLC 主程序 | `h2o2_final.awl` | 现场稳定顺控、联锁、补水、流量和模拟量处理程序 |
| 网页调试面板 | `plc_dashboard.py` | Flask + Snap7 调试面板，适合参数设置、诊断和联调 |
| 原生上位机 | `h2o2_monitor/` | Rust + Slint 桌面组态监控软件，适合现场全屏展示 |
| 设计资源 | `PNG/` | 上位机底图、设备图标和组态界面资源 |
| 使用说明 | `PLC使用说明书.md` | PLC 地址、流程、联锁、监控软件和运维说明 |

## 2. 通信与运行入口

| 项目 | 默认地址/命令 | 用途 |
|---|---|---|
| PLC 地址 | `192.168.1.11` | S7-200 SMART CPU 通信地址 |
| S7 TCP | `192.168.1.11:102` | 原生上位机直连 PLC |
| 网页调试 | `py .\plc_dashboard.py` | 启动 Flask 网页调试面板 |
| 网页访问 | `http://127.0.0.1:5000` | 本机浏览器访问 |
| 上位机开发运行 | `cd h2o2_monitor && cargo run` | 编译并运行 Rust/Slint 上位机 |
| 上位机正式编译 | `cd h2o2_monitor && cargo build --release` | 生成 `target/release/h2o2_monitor.exe` |

S7-200 SMART 的 S7 TCP 连接数有限。正式运行或刷 PLC 程序前，应避免 Micro/WIN SMART、网页调试面板、Snap7 工具和 `h2o2_monitor` 同时长期占用 PLC 通信连接。

## 3. 核心工艺逻辑

1. 开机后进入补水升压阶段，空压机 `Q1.1` 开启。
2. 任一路液位低于 45cm 时打开对应补水阀，并联动制水机 `Q1.0`。
3. 两路液位达到最低运行条件且高压罐压力达标后，开启阳极阀 `Q0.2` 和阳极泵 `M1.0/AQW32`。
4. 阳极运行延时 10 秒后，开启阴极阀 `Q0.3` 和阴极泵 `M1.1/AQW34`。
5. 阴阳极流量同时达标后进入生产联锁，自动允许直流仪输出 `Q1.2`。
6. 关机先停直流、制水和阴极侧，10 分钟后停止阳极侧和空压机。

## 6. 安全联锁

- 任一路液位低于 20cm，置低液位报警并强制关闭 `Q1.2`。
- 生产阶段阳极流量必须大于等于 0.5L/min，阴极流量必须大于等于 0.05L/min。
- 任一路生产流量不足，置 `V2303.5` 生产缺流报警并关闭 `Q1.2`。
- 急停会关闭阀、泵、制水机、空压机和直流输出，并清空顺控步骤。
- 原生上位机只做读取和展示，不下发开机、关机、急停或参数写入命令。

## 7. 上位机当前能力

- 1280×1024 无边框现场全屏界面，启动后固定在屏幕左上角。
- 基于设计底图显示电解槽、阳极/阴极侧设备、制水机、空压机和管道。
- S7 TCP 直连 PLC，默认 `192.168.1.11:102`，支持 `H2O2_PLC_ADDR` 覆盖。
- 实时显示高压罐压力、阳极压力、阴极压力、阳极液位、阴极液位、阳极流量和阴极流量。
- 每段管道流动动画独立控制，断线、报警或急停时全部停止流动。
- 停机设备使用黑色变暗效果，运行设备保持正常显示。
- 底部状态区显示“系统正常运行”或“系统故障/报警”，连续点击三次可退出程序。
