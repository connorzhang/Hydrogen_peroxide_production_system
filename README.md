# 双氧水生产控制系统

当前稳定调试版本用于 S7-200 SMART 双氧水生产平台，包含 PLC 顺控程序、现场网页监控面板和使用说明文档。

## 当前稳定版本

- PLC 程序：`h2o2_final.awl`
- 网页监控：`plc_dashboard.py`
- PLC 地址：`192.168.1.11`
- 网页地址：`http://127.0.0.1:5000` 或 `http://192.168.0.244:5000`

## 核心工艺逻辑

- 开机后进入补水升压：空压机 `Q1.1` 开启，任一路液位低于 45cm 时打开对应补水阀并联动制水机 `Q1.0`
- 两路液位达到最低运行条件且高压罐压力达标后，开启阳极阀 `Q0.2` 和阳极泵 `M1.0/AQW32`
- 阳极运行延时 10 秒后，开启阴极阀 `Q0.3` 和阴极泵 `M1.1/AQW34`
- 阴阳极流量同时达标后进入生产联锁，自动允许直流仪输出 `Q1.2`
- 关机先停直流、制水和阴极侧，10 分钟后停止阳极侧和空压机

## 模拟量与参数

- 压力传感器按 4-20mA、0-600kPa 换算：`AIW16` 高压罐，`AIW18` 阳极压力，`AIW20` 阴极压力
- 液位传感器按 4-20mA、0-200cm 换算：`AIW22` 阳极液位，`AIW24` 阴极液位
- 阳极泵默认 `VW2020=8294`，约 3.0V
- 阴极泵默认 `VW2026=5253`，约 1.9V
- 阳极流量系数 `VD2016=221000.0`
- 阴极流量系数 `VD2028=88400.0`

## 安全联锁

- 任一路液位低于 20cm，置低液位报警并强制关闭 `Q1.2`
- 生产阶段阳极流量必须大于等于 0.5L/min，阴极流量必须大于等于 0.05L/min
- 任一路生产流量不足，置 `V2303.5` 生产缺流报警并关闭 `Q1.2`
- 急停会关闭阀、泵、制水机、空压机和直流输出，并清空顺控步骤

py .\plc_dashboard.py
