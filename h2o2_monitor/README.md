# 双氧水生产系统 - 原生上位机监控软件

本目录是双氧水生产系统的 Rust/Slint 原生桌面监控软件。软件用于工控机现场展示，直接通过 S7 TCP 读取 S7-200 SMART PLC 数据，不依赖 Python、Flask 或浏览器。

## 1. 软件定位

| 项目 | 当前口径 |
|---|---|
| 运行平台 | Windows 工控机 |
| UI 技术 | Rust + Slint |
| 通信方式 | S7 TCP 直连 PLC |
| 默认 PLC | `192.168.1.11:102` |
| 现场分辨率 | `1280×1024` |
| 窗口形态 | 无边框全屏，启动后位于屏幕左上角 |
| 当前能力 | 读取 PLC 数据、显示组态画面、显示设备状态、显示管道流动 |
| 当前边界 | 不下发开机、关机、急停和参数写入命令 |

## 2. 通信说明

默认 PLC 地址：

```text
192.168.1.11:102
```

可通过环境变量覆盖：

```powershell
$env:H2O2_PLC_ADDR="192.168.1.11:102"
cargo run
```

连接策略：

- 尝试多个 S7 remote TSAP：`0x0301`、`0x0101`、`0x0201`、`0x0100`。
- 连接成功后每 500ms 读取一次 PLC 数据。
- 通信断开后界面进入故障状态，并每 3s 静默重连。
- 断线、报警或急停时，所有管道流动动画停止。

## 3. 界面功能

| 功能 | 说明 |
|---|---|
| 组态底图 | 使用 `PNG/整体效果.png` 作为整体设计底图 |
| 设备状态 | 运行设备正常显示，停机设备使用黑色变暗覆盖 |
| 管道流动 | 每段流动管道独立控制，按 PLC 状态联动启停 |
| 数值显示 | 显示压力、液位和流量等现场数据 |
| 状态栏 | 底部显示“系统正常运行”或“系统故障/报警” |
| 退出方式 | 连续点击底部状态区域三次退出程序 |
| 窗口移动 | 无边框窗口支持鼠标拖动移动 |

## 7. 运行前注意

S7-200 SMART 的 S7 TCP 连接数有限，正式运行时只保留必要的 PLC 通信主站。运行本程序前建议关闭：

- `plc_dashboard.py` 网页调试服务。
- Micro/WIN SMART 在线监控。
- Snap7/S7 TCP 调试工具。
- 其它可能占用 `192.168.1.11:102` 的程序。

刷 PLC 程序前也需要退出本上位机，避免占用 PLC 通信连接。

## 8. 编译指南

Windows 上当前项目使用 `x86_64-pc-windows-msvc` 工具链，需要先安装：

- Rust stable 工具链。
- Visual Studio Build Tools 2019/2022/2026。
- `Desktop development with C++` 工作负载。
- MSVC C++ Build Tools。
- Windows 10/11 SDK。

安装完成后重新打开终端，确认以下命令可用：

```powershell
rustc --version
cargo --version
cl
link
```

开发运行：

```powershell
cargo run
```

Release 编译：

```powershell
cargo build --release
```

编译完成后，在 `target/release/` 目录下生成 `h2o2_monitor.exe`。
