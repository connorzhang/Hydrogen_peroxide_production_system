# 原生上位机说明

原生上位机位于 `h2o2_monitor` 目录，使用 Rust + Slint 实现，面向现场工控机全屏显示。

## 软件定位

| 项目 | 当前口径 |
|---|---|
| 运行平台 | Windows 工控机 |
| UI 技术 | Rust + Slint |
| 通信方式 | S7 TCP 直连 PLC |
| 默认 PLC | `192.168.1.11:102` |
| 现场分辨率 | `1280×1024` |
| 窗口形态 | 无边框全屏，启动后位于屏幕左上角 |
| 当前能力 | 读取 PLC 数据、显示组态画面、显示设备状态、显示管道流动 |
| 当前边界 | 不下发开机、关机、急停和参数写入命令 |

## 运行方式

```powershell
cd .\h2o2_monitor
cargo run --release
```

正式测试时可直接复制 Release 版 `h2o2_monitor.exe` 到工控机运行。默认 PLC 地址为 `192.168.1.11:102`，如现场 PLC 地址不同，可通过环境变量 `H2O2_PLC_ADDR` 指定。

## 界面能力

- 适配 `1280×1024` 工控屏，无标题栏全屏显示，启动位置固定在屏幕左上角。
- 使用 `PNG/整体效果.png` 作为静态底图，叠加实时压力、液位、流量和设备状态。
- 设备停机时以黑色状态显示，运行时恢复正常图标显示。
- 每段管线流动均为独立组件，按阀门、制水机、空压机、报警和急停状态联动。
- PLC 断线、系统报警或急停时，全部流动动画停止，底部状态显示故障/报警。
- 底部状态区域连续点击三次可退出程序。

## 已展示字段

| 界面内容 | PLC 地址/来源 | 说明 |
|---|---|---|
| 高压罐压力 | `VD2100` | kPa |
| 阳极压力 | `VD2104` | kPa |
| 阴极压力 | `VD2108` | kPa |
| 阳极液位 | `VD2112` | cm |
| 阴极液位 | `VD2116` | cm |
| 阳极流量 | `VD1310` | 数值来源为 PLC 实时值 |
| 阴极流量 | `VD1330` | 数值来源为 PLC 实时值 |
| 阳极阀/泵状态 | `Q0.2` | 用于设备变暗和阳极管线流动 |
| 阴极阀/泵状态 | `Q0.3` | 用于设备变暗和阴极管线流动 |
| 制水机状态 | `Q1.0` | 用于纯水相关管线联动 |
| 空压机状态 | `Q1.1` | 用于压缩机管线联动 |

## 流动联动逻辑

- 纯水机到阴极侧：系统无报警、无急停、制水机运行、阴极阀打开。
- 阴极侧管道：系统无报警、无急停、阴极阀打开。
- 纯水机到阳极侧：系统无报警、无急停、制水机运行、阳极阀打开。
- 阳极侧管道：系统无报警、无急停、阳极阀打开。
- 空压机管道：系统无报警、无急停、空压机运行。

## 运行前注意

运行本程序前建议关闭 `plc_dashboard.py`、Micro/WIN SMART 在线监控、Snap7/S7 TCP 调试工具和其它可能占用 `192.168.1.11:102` 的程序。
