# PLC 使用说明

完整 PLC 使用说明请以项目根目录 `PLC使用说明书.md` 为准。本页同步当前现场稳定版的核心信息，用于文档中心查阅。

## 硬件与通信

- PLC：S7-200 SMART CPU ST30
- 模拟量输入模块：AE08，地址 `AIW16` ~ `AIW30`
- 模拟量输出模块：AQ02，地址 `AQW32`、`AQW34`
- PLC 通信地址：`192.168.1.11`
- 原生上位机 S7 TCP 地址：`192.168.1.11:102`

## 主要输入输出

| 类型 | 地址 | 名称 |
|---|---|---|
| DI | `I0.0` | 阳极流量脉冲 |
| DI | `I0.1` | 开机按钮 |
| DI | `I0.2` | 关机按钮 |
| DI | `I0.3` | 急停 |
| DI | `I0.6` | 阴极流量脉冲 |
| DO | `Q0.0` | 阳极补水阀 |
| DO | `Q0.1` | 阴极补水阀 |
| DO | `Q0.2` | 阳极控制阀 |
| DO | `Q0.3` | 阴极电磁阀 |
| DO | `Q1.0` | 制水机 |
| DO | `Q1.1` | 空压机 |
| DO | `Q1.2` | 直流仪输出允许 |

## 开机流程

1. 触发开机按钮 `I0.1` 或网页开机命令 `V2302.0`。
2. `VB100=10`：空压机 `Q1.1` 打开，液位控制按 45/55cm 滞回补水。
3. 阳极、阴极液位均不低于 45cm，且高压罐压力达到 `VD2000` 后进入 `VB100=20`。
4. `VB100=20`：阳极阀 `Q0.2` 打开，阳极泵 `M1.0/AQW32` 运行。
5. 延时 `VW2024` 后进入 `VB100=30`，阴极阀 `Q0.3` 和阴极泵 `M1.1/AQW34` 打开。
6. 阳极流量大于等于 0.5L/min 且阴极流量大于等于 0.05L/min，同时无低液位报警时，打开直流仪输出允许 `Q1.2`。

## 关机流程

1. 触发关机按钮 `I0.2` 或网页关机命令 `V2302.1`。
2. `VB101=10`：立即关闭直流输出、制水机、补水阀、阴极阀和阴极泵。
3. `VB101=20`：阳极阀、阳极泵和空压机保持 10 分钟延时。
4. 延时结束后关闭阳极阀、阳极泵和空压机，清空 `VB100/VB101`。

## 安全联锁

- 任一路液位低于 20cm 时，立即关闭 `Q1.2`。
- 生产阶段任一路流量不足时，置 `V2303.5` 并关闭 `Q1.2`。
- 急停触发时，关闭 `Q0.0~Q0.3`、`Q1.0~Q1.2`、泵使能和顺控步骤。

## S7 通信占用注意

S7-200 SMART 的 S7 通信连接数有限，`h2o2_monitor`、`plc_dashboard.py`、Micro/WIN SMART、Snap7 调试脚本和其它第三方 S7 主站不要长期同时占用 PLC。
