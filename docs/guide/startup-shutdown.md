# 开关机说明

## 开机流程

1. 打开总电源，确认急停回路正常。
2. 按下开机按钮 `I0.1`，或在网页上发送开机命令 `V2302.0`。
3. 系统进入 `VB100=10` 补水升压阶段：空压机 `Q1.1` 开启，液位按 45/55cm 滞回补水，任一路补水阀打开时制水机 `Q1.0` 打开。
4. 当阳极液位和阴极液位均不低于 45cm，且高压罐压力达到设定阈值 `VD2000` 后，进入 `VB100=20` 阳极运行阶段。
5. 阳极运行延时 `VW2024` 后，进入 `VB100=30` 阴阳极运行阶段。
6. 生产联锁满足后打开直流仪输出允许 `Q1.2`。

## 关机流程

1. 按下关机按钮 `I0.2`，或在网页上发送关机命令 `V2302.1`。
2. `VB101=10`：关闭直流仪输出、制水机、补水阀、阴极阀和阴极泵。
3. `VB101=20`：阳极阀、阳极泵和空压机保持 10 分钟延时。
4. 延时结束后关闭阳极控制阀、阳极泵和空压机，并清空 `VB100/VB101`。

## 急停逻辑

急停输入 `I0.3` 或网页急停命令 `V2302.2` 触发后，立即关闭补水阀、阳极阀、阴极阀、制水机、空压机、直流仪输出和两路泵使能。

## 原生上位机监控

- 原生上位机程序位于 `h2o2_monitor` 目录，正式测试时可直接运行 Release 版 `h2o2_monitor.exe`。
- 默认 PLC 地址为 `192.168.1.11:102`，如现场 PLC 地址不同，可通过 `H2O2_PLC_ADDR` 环境变量指定。
- 原生上位机适配 `1280×1024` 工控屏，无标题栏全屏显示。
- PLC 断线、系统报警或急停时，全部流动效果停止，底部状态显示故障/报警。
- 底部状态区域连续点击三次可退出程序。
- 原生上位机当前只读取 PLC 数据并展示，不下发开机、关机、急停或参数修改命令。

## S7 通信占用注意

S7-200 SMART 的 S7 通信连接数有限，不建议 `h2o2_monitor`、`plc_dashboard.py`、Micro/WIN SMART、Snap7 调试脚本或其它 S7 主站长期同时连接 PLC。刷 PLC 程序、下载程序或在线监控前，建议先关闭网页调试面板和原生上位机。
