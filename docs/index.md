# 双氧水生产控制系统

>  当前版本: v2026.06.21.2337 |  最后同步: 2026-06-21 23:37:46 |  构建 Commit: 37b5b91

本项目用于 S7-200 SMART 双氧水生产平台，当前稳定版本由 PLC 顺控程序、网页调试面板、Rust/Slint 原生上位机和现场使用文档组成。系统核心工艺为电解槽将水分解为氢气和氧气，并利用氧气制备双氧水。

## 当前稳定版本

| 模块 | 文件/入口 | 说明 |
|---|---|---|
| PLC 主程序 | `h2o2_final.awl` | 现场稳定顺控、联锁、补水、流量和模拟量处理程序 |
| 网页调试面板 | `plc_dashboard.py` | Flask + Snap7 调试面板，适合参数设置、诊断和联调 |
| 原生上位机 | `h2o2_monitor/` | Rust + Slint 桌面组态监控软件，适合现场全屏展示 |
| 设计资源 | `PNG/` | 上位机底图、设备图标和组态界面资源 |

## 通信与运行入口

| 项目 | 默认地址/命令 | 用途 |
|---|---|---|
| PLC 地址 | `192.168.1.11` | S7-200 SMART CPU 通信地址 |
| S7 TCP | `192.168.1.11:102` | 原生上位机直连 PLC |
| 网页调试 | `py .\plc_dashboard.py` | 启动 Flask 网页调试面板 |
| 网页访问 | `http://127.0.0.1:5000` | 本机浏览器访问 |
| 上位机正式编译 | `cd h2o2_monitor && cargo build --release` | 生成 `target/release/h2o2_monitor.exe` |

## 现场注意事项

- S7-200 SMART 的 S7 TCP 连接数有限，正式运行或刷 PLC 程序前，应避免 Micro/WIN SMART、网页调试面板、Snap7 工具和 `h2o2_monitor` 同时长期占用 PLC 通信连接。
- 原生上位机当前只读取 PLC 数据并展示，不下发开机、关机、急停或参数写入命令。
- PLC 断线、系统报警或急停时，原生上位机全部流动动画停止，底部状态显示故障/报警。
