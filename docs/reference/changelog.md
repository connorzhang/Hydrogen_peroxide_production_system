# 更新记录

## 2026-06-19 - Rust/Slint 原生上位机组态版

- 新增并整理 `h2o2_monitor` 原生桌面监控软件，采用 Rust + Slint + S7 TCP 直连 PLC 架构。
- 上位机默认连接 `192.168.1.11:102`，支持通过 `H2O2_PLC_ADDR` 覆盖 PLC 地址。
- S7 连接兼容多个 remote TSAP：`0x0301`、`0x0101`、`0x0201`、`0x0100`。
- 上位机读取 DI、DO、M 区、顺控步骤、压力、液位、流量、报警和泵输出相关寄存器。
- 新增 1280×1024 无边框现场全屏界面，启动后固定在屏幕左上角。
- 使用 `PNG/整体效果.png` 作为组态底图，并叠加设备状态覆盖和动态管线流动效果。
- 停机设备恢复黑色变暗效果，运行设备正常显示。
- 将每一段管线流动拆成独立控制属性，并按制水机、空压机、阳极阀、阴极阀、报警和急停状态联动。
- 通信断开、报警或急停时，所有流动动画停止，底部状态显示“系统故障/报警”。
- 底部状态区域支持连续点击三次退出，窗口支持无边框拖动。

## 当前稳定版 - 2026-06-17

- 新增并稳定 `h2o2_final.awl`，作为当前现场 PLC 主程序。
- 新增并稳定 `plc_dashboard.py`，作为 Flask + Snap7 网页监控和调试面板。
- 修正压力传感器换算为 4-20mA、0~600kPa。
- 修正液位传感器换算为 4-20mA、0~200cm。
- 补水逻辑独立为 `SBR_LEVEL:SBR5`，只在开机状态执行，45cm 开阀、55cm 停阀。
- 新增生产阶段流量联锁：阳极 ≥0.5L/min、阴极 ≥0.05L/min 且无低液位报警时允许 `Q1.2`。
- 新增生产缺流报警 `V2303.5`，任一路生产流量不足时关闭 `Q1.2`。
